# Skill: cardápio digital whitelabel

- Priorize HTML/CSS/JS estático ou SPA leve (sem build pesado).
- Estrutura mínima: `index.html`, `styles.css`, `app.js`.
- Whitelabel: variáveis CSS `--brand-color`, `--logo-url`, nome do restaurante em config no topo do JS.
- Seções: header, categorias, itens com preço, footer com contato.
- Mobile-first; botões grandes para toque.
- Não use frameworks que exijam `npm run build` na VPS grátis, salvo se a spec pedir.
